# Railway Management System

## Overview
A DBMS project developed using SQL to manage railway operations including trains, passengers, tickets, stations, and platforms.

## Features
- Train Management
- Passenger Management
- Ticket Booking
- Station Management
- Platform Allocation

## Technologies Used
- SQL
- DBMS
- MySQL
